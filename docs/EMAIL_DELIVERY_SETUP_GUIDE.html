What is being configured?

The website quote forms already collect and validate customer enquiries. WordPress now needs an authorised email service to deliver each enquiry to the business inbox.

The client never needs to give the developer their Google password. For the Gmail method, the client signs into Google privately and clicks Allow. The developer never sees or stores the password.

How a quote email is routed

Recipientsppainting.remodeling@gmail.com
SenderThe authorised Gmail account under Option 1, or the confirmed domain mailbox under Option 2.
Reply-ToThe customer email entered in the quote form. Pressing Reply addresses the customer.

Before beginning

  • Keep the WordPress administrator dashboard open.
  • Confirm WP Mail SMTP is installed and active.
  • Use a private/incognito window for the client’s Google authorisation if multiple Google accounts are signed in.
  • Never send passwords, OAuth Client Secrets or recovery codes by email or chat.
  • Use controlled test information only until delivery is confirmed.
Option 1 · Recommended

Google / Gmail API

This method sends website email through Google’s HTTPS API. It avoids GoDaddy’s blocked external SMTP ports and does not require a new domain mailbox.

Account ownership: the Google project and final authorisation should be completed while signed into sppainting.remodeling@gmail.com. The client may complete the login/Allow step themselves while the developer provides guidance.

Step 1 — Select Gmail in WordPress

  1. Open WordPress Dashboard → WP Mail SMTP → Settings → General.
  2. Set the values below.
From Emailsppainting.remodeling@gmail.com
Force From EmailOn
From NameSuperior Plus Painting & Remodeling
Force From NameOn
MailerGoogle / Gmail

WP Mail SMTP Free requires manual setup. One-Click Setup is a paid Pro feature. Copy the Authorized Redirect URI shown in WP Mail SMTP and keep the WordPress tab open.

Step 2 — Create the Google Cloud project

1

Step 3 — Enable Gmail API

  1. Open APIs & Services → Library.
  2. Search for Gmail API.
  3. Open the Gmail API result and click Enable.

  2. Name it Superior Plus WordPress.
  3. Leave Authorized JavaScript origins empty.

https://connect.wpmailsmtp.com/google/

Option 1 · Final connection

Authorise and test Gmail

Step 7 — Connect WP Mail SMTP

  1. Return to WP Mail SMTP → Settings → General.
  2. Paste the Google Client ID and Client Secret.
  3. Click Save Settings.
  4. Click Allow plugin to send emails using your Google account.
  5. The client signs into sppainting.remodeling@gmail.com privately and approves the permission request.
No password is shared. Google returns an access authorisation to WordPress. The client can revoke it later from their Google Account security settings.

If Google shows “This app isn’t verified” for the private app, select Advanced, continue to the app, and approve it. Only proceed when the client recognises the project created in this guide.

Step 8 — Test email delivery

  1. Open WP Mail SMTP → Tools → Email Test.
  2. Send a test to an inbox you can access.
  3. Confirm it actually appears in Inbox, Spam or All Mail. A green “sent” banner alone is not enough.
  4. Submit one website quote marked TEST QUOTE — PLEASE IGNORE.
  5. Confirm the quote reaches sppainting.remodeling@gmail.com.
  6. Press Reply and confirm the reply is addressed to the email entered in the quote form.

Gmail limits and suitability

A standard Gmail account is generally limited to approximately 500 outgoing messages per day. Each quote normally uses one message, so this is suitable for a painting-business contact form, but not for newsletters or bulk marketing.

Common Gmail errors

redirect_uri_mismatchThe URI in Google does not exactly match the WP Mail SMTP Authorized Redirect URI.
invalid_clientRe-copy the Client ID without extra spaces.
403 access_deniedPublish the application or add/authorise the correct Google user.
Login RequiredReturn to WP Mail SMTP and complete the Allow/authorisation step.
Option 2 · Alternative

GoDaddy SMTP Relay

This method uses GoDaddy’s internal Managed WordPress relay. It does not use the client’s Gmail password, but it requires a legitimate sender address under the website’s domain and correct DNS authentication.

Do not use Gmail as the From Email with this relay. GoDaddy states that third-party sender domains such as Gmail can fail authentication because the website owner does not control Gmail’s DNS.

Requirements

  • Authorised access to the client’s GoDaddy hosting/email account, or assistance from GoDaddy Support.
  • A real, confirmed mailbox ending in @sppaintingremodeling.com.au.
  • Authorised access to Cloudflare DNS, because the domain currently uses Cloudflare nameservers.
  • The sender mailbox address confirmed by the client or GoDaddy. Do not invent or type an address that has not been created.

Step 1 — Confirm the sender mailbox

In the client’s GoDaddy account, open the Email & Office area and confirm the exact active mailbox under sppaintingremodeling.com.au. If none exists, the client must decide whether to create one before using this option.

The business recipient may remain sppainting.remodeling@gmail.com. The domain mailbox is the authorised sender, not necessarily the destination.

Step 2 — Configure WP Mail SMTP

Open WP Mail SMTP → Settings → General, select Other SMTP, and enter:

SMTP Hostrelay-hosting.secureserver.net
EncryptionNone
SMTP Port25
Auto TLSOff
AuthenticationOff
SMTP UsernameLeave blank
SMTP PasswordLeave blank
From EmailThe exact active domain mailbox confirmed in Step 1
Force From EmailOn
From NameSuperior Plus Painting & Remodeling
Force From NameOn
Option 2 · DNS and testing

Authorise the GoDaddy relay

Step 3 — Add or merge the SPF record

Open Cloudflare → sppaintingremodeling.com.au → DNS. Search existing TXT records for a value beginning with v=spf1.

If no SPF record exists, add:

TypeTXT
Name@
Contentv=spf1 include:secureserver.net -all
TTLAuto
Never publish two separate SPF records. If an SPF record exists when configuring the site, merge include:secureserver.net into that record or ask GoDaddy/Cloudflare support to merge it safely.

Step 4 — Test actual delivery

  1. Wait for DNS propagation. Allow at least 30 minutes before the first retest.
  2. Open WP Mail SMTP → Tools → Email Test.
  3. Send to an inbox you can access.
  4. Verify the message appears in Inbox, Spam or All Mail.
  5. Submit a test quote and verify the business receives it.
Important: WP Mail SMTP’s “Test email sent successfully” only proves that GoDaddy accepted the message. The test is complete only when the message appears in the destination mailbox.

If GoDaddy accepts but nothing arrives

Send this to GoDaddy Advanced Hosting Support:

We configured relay-hosting.secureserver.net on port 25 with no encryption and no authentication. WP Mail SMTP reports success, but the recipient does not receive the message. Please confirm the exact authorised From mailbox for this Managed WordPress account and verify the relay logs, SPF requirements and delivery status.

Final production checklist

  • The selected mailer is connected under a client-controlled account.
  • The WP Mail SMTP test message is physically present in the destination inbox.
  • The Superior Plus quote recipient is sppainting.remodeling@gmail.com.
  • A live quote marked as a test reaches the client.
  • Reply addresses the customer email entered in the form.
  • Inbox, Spam and All Mail have been checked.
  • Temporary developer accounts and test recipients have been removed.
  • No Google password, Client Secret or recovery code has been shared.
