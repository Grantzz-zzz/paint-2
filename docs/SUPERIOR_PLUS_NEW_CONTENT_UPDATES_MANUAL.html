Purpose of this manual

This manual explains the controls introduced for editing long client-supplied content without changing theme code. It focuses on choosing the correct field for each type of content so the website remains readable and visually consistent.

The plugin controls content. The theme controls the layout, responsive design, card dimensions, colours, typography and spacing. Normal content work should therefore be completed through the plugin fields described below.

Before editing

2. Install and verify the update

  1. Create a current backup through Superior Plus → Content Backup.
  2. Go to Plugins → Add New Plugin → Upload Plugin.
  3. Upload superior-plus-content-2.6.1.zip and approve replacing the installed version.
  4. Confirm Superior Plus Content 2.6.1 is active.
  5. Confirm the active theme is Superior Plus 3.5.1.
  6. Clear the WordPress/page cache and any hosting or CDN cache.
  7. Open the homepage in a private/incognito browser window and check the footer, navigation and one edited page.
Do not run Restore original content as part of a normal plugin update. Updating the plugin should preserve saved content. Restore is a separate recovery action for one managed record.

Recommended editing sequence

  1. Back up.
  2. Edit one page.
  3. Use Preview.
  4. Update or Publish.
  5. Check desktop and mobile.
  6. Continue to the next page.

Daily workflow

5. Add, edit, reorder and delete sections

Add a new section

  1. Open the required record and scroll to Superior Plus editable content.
  2. Find Additional flexible sections — Eyebrow, heading, description & list or Flexible content sections.
  3. Click Add section.
  4. Complete only the fields needed for that section.
  5. Add list items individually when the content is a list.
  6. Use the movement controls to place the section in the required order.
  7. Preview, then click Update or Publish.

Edit an existing section

Change the eyebrow, heading, description or individual list items inside that section. Editing one section does not require re-entering the other sections.

Delete a section

Click the section's Delete control, then save the page. Deleting a section removes that section only. It does not delete the page, service, images or unrelated sections.

Do not use Restore original content to remove one section. Restore replaces the managed record with approved defaults and can discard other edits on that same record.
Readable long copy

6. Multiple paragraphs

The description field supports paragraph breaks. Press Enter twice so there is one completely blank line between paragraphs.

Correct entryOur painters inspect the surfaces and discuss the required finish.

Preparation is then matched to the substrate, existing coating and condition of the property.
GoodSeparate two distinct ideas with a blank line. The website renders them as separate paragraphs.
AvoidPasting five paragraphs with no blank lines. WordPress will treat them as one dense paragraph.

Keeping wording verbatim

You may keep the client's wording exactly while improving presentation. Split the supplied wording only at natural paragraph boundaries and move enumerated benefits into list items. Do not rewrite the sentences unless the client approves wording changes.

Formatting that is intentionally restricted

The field stores safe plain text rather than arbitrary HTML. Script tags and unsafe markup are removed. Bold, custom colours, custom font sizes and pasted document styling are not supported because the theme controls typography consistently.

Clean lists

7. Bullet and numbered content

Recommended method: separate list items

  1. Open the flexible section.
  2. Under List items, click Add item.
  3. Paste or type one item only.
  4. Repeat for every point.
  5. Reorder or delete individual items as needed.
  6. Save and preview.
Example list items
  • Protect timber from UV damage
  • Reduce moisture penetration
  • Improve durability
  • Enhance the natural beauty of timber

If the source document already contains bullets

Copy each bullet without its bullet symbol into its own list-item field. This is more dependable than pasting a formatted list from Word or a PDF into one description box.

Numbered steps

If exact numbering is important, include the number in the item's text, for example 1. Inspect the surfaces. For normal benefit lists, omit manual numbers and allow the theme's compact list styling to provide the visual marker.

Why pasted bullets sometimes become one sentence: PDF and messaging applications may copy visual bullets without real line breaks. Separate list-item controls prevent that formatting loss.
Long hero introductions

8. Hero See more / Show less

The hero introduction can contain multiple paragraphs. When its combined text exceeds approximately 330 characters, the theme automatically shows a shortened preview followed by See more.

  • The editor does not need to insert the See more button.
  • Selecting See more reveals the complete wording.
  • Selecting Show less returns to the compact hero.
  • The control is keyboard accessible and exposes its expanded state to assistive technology.
  • The original full text remains available to the page; it is not deleted or shortened in WordPress.
Field: use Hero introduction. Do not place the complete hero description inside the Hero title or Hero accent line.

Recommended hero composition

FieldRecommended length
Hero eyebrow2–6 words
Hero title2–8 words
Hero accent line2–8 words
Hero introductionShort copy displays normally; long copy collapses automatically
Prevent broken layouts

9. Cards versus full content sections

A card is a small preview component. It is not a replacement for a full page section. Putting an entire service-page paragraph into a card creates the tall, narrow block shown in the reported homepage issue.

Content typeCorrect fieldAvoid
Short trust promiseTrust cards — Heading | DescriptionLong service explanations
Homepage service previewServices-directory summary on the service recordFull service-page copy
Complete explanationFlexible content section descriptionSmall card description
Several benefits or inclusionsFlexible section list itemsBullets pasted into a one-line card field
Full service detailService document/flexible sectionsHomepage card

Fix the “Our Professional Painting Services” card

  1. Go to Pages → Home → Edit.
  2. Find Trust cards — Heading | Description.
  3. Keep the card heading concise and replace its description with a 15–35 word summary.
  4. Create an Additional flexible section for the complete wording.
  5. Use the flexible section's list items for Residential Painting, Interior Painting and the other named services.
  6. Preview the homepage at desktop and mobile widths before updating.
Current limitation: trust cards do not have their own See more control. The hero introduction does. For long trust-card copy, move the full wording into a flexible section.
Safe editing model

10. Blank, untouched and deleted content

SituationResult after savingWhat to do
The plugin field is blank and you have never edited it, but original default content is visible.The default content remains visible.Leave it untouched when editing another field.
You enter new content.Your saved content replaces the default for that field.Preview and confirm the result.
You clear a previously configured normal text field.The field remains intentionally blank after Plugin 2.6.1.Delete all characters and save.
You delete one card, list item or flexible section.That row disappears; unrelated rows remain.Use the row's Delete control and save.
You delete every row from a previously configured structured field.The saved collection becomes empty.Preview carefully because the complete component may disappear.
You type spaces into a field.Spaces are sanitized as blank; they are not reliable hidden content.Use a genuine deletion workflow, not spaces.
Special case — visible fallback with a never-configured blank field: if clearing the already blank control does not hide the fallback, first save a temporary real value so the field becomes configured, then clear it and save again. Preview after both saves. A space does not count as real content.

Restore original content

This action restores only the current managed record to approved Superior Plus defaults. It should be used for recovery, not routine deletion. It does not restore other pages, menus, enquiries or email configuration.

Other managed records

13. Instructions for the remaining pages

About

Use existing About-specific fields for the approved approach, standards and roots sections. Use flexible sections for new topics containing an eyebrow, heading, paragraphs or lists. Keep flip-card text compact.

Our Process

Use the dedicated process-step controls for the main sequence. Use flexible sections for detailed explanations, lists or supporting information. Do not force several paragraphs onto a flip card.

FAQs

Edit individual questions under Superior Plus → FAQs. Use the FAQs page fields for page introductions and follow-up sections such as Why Clients Choose Us, Share Your Experience and Request a Free Quote. Use flexible sections for additional explanatory content.

Contact

Use the dedicated form fields and contact-step controls for the form. Flexible sections can add preparation notes or service information, but they do not create new form inputs.

Service Areas and individual suburbs

Edit directory copy on the Service Areas page. Edit each suburb record for its own hero, descriptions, images and flexible sections. A missing area image must be replaced through that area's Media Library control, then the area record must be updated.

Gallery and Projects

Use Projects for individual project titles, types and image collections. Flexible sections can add project background, scope or results. Use the gallery control—not the description field—to add images.

Blog articles

Use article-specific fields for category, read time, takeaways and references. Use flexible sections for additional article topics that need paragraphs and lists.

Media workflow

14. Images and media

Add or replace one image

  1. Open the required page, service, area or project.
  2. Find the correct Hero image, Secondary image or other named media field.
  3. Click Choose or replace.
  4. Upload a file or select an existing Media Library item.
  5. Add meaningful alt text describing the image's content and purpose.
  6. Click Update; selecting media alone does not publish it.

Add several gallery items

Use Add images or videos, choose the Media Library items, reorder them inside the gallery control, then save the record.

Hawthorn East or Camberwell missing photos

  1. Go to Superior Plus → Service Areas.
  2. Edit Hawthorn East or Camberwell.
  3. Choose/replace the relevant hero or area image.
  4. Enter accurate alt text.
  5. Update and clear caches.
If an image still does not appear: confirm the image loads in the Media Library, the live site is running Theme 3.5.1 and Plugin 2.6.1, then clear page/CDN/browser caches.
Capacity planning

15. Limits and content planning

ControlLimitPlanning recommendation
Flexible sections per field40Group related content. Do not create one section for every sentence.
List items per flexible section60Use one idea per item. Split unrelated lists into different sections.
Service document + additional sectionsUp to 40 in each fieldUse document sections for core narrative and additional sections for new supporting copy.
Services-directory summary400 charactersAim for 15–35 words so cards remain balanced.
Hero introduction1,200 charactersLong copy is allowed and automatically collapses after about 330 characters.

During testing, 40 sections with dense lists rendered successfully across representative homepage, standard page, directory, service, area, article and project routes at desktop and mobile sizes. Nevertheless, content should be divided according to reader needs—not filled to the technical maximum without reason.

Values above the hard limits are discarded during saving. If more content is genuinely required, create another appropriate record/page or revise the information architecture before editing code.
Quality control

16. Preview and publishing checklist

  • Confirm the correct page, service, area, project or article is open.
  • Confirm the eyebrow is a small label, not a paragraph.
  • Confirm the heading is concise and contains no bullet list.
  • Confirm paragraphs have blank lines between them.
  • Confirm every bullet is a separate list item.
  • Confirm card descriptions are summaries rather than full sections.
  • Confirm images appear and have useful alt text.
  • Use Preview before Update/Publish.
  • Check desktop layout.
  • Check a mobile-sized browser or real phone.
  • Test See more and Show less where shown.
  • Test card links and CTA destinations.
  • Clear caches if the live page still shows the old version.

Safe batch-edit method

For a large client document, edit and verify one page at a time. Keep a checklist of PDF headings and mark each one only after the wording and placement have been verified on the live preview.

Problem solving

17. Troubleshooting

ProblemLikely causeResolution
A card becomes extremely tall or narrow.Long page copy was placed in a card description.Shorten the card summary and move the full copy into a flexible section.
Bullets become one sentence.The source did not contain real line breaks, or everything was pasted into one description.Create separate list items in the flexible-section editor.
Untouched default content remains after editing another field.This is the intended safe-save behavior.No action is required.
You want visible default content to disappear.The field may never have been configured.Save a real temporary value, then clear the field and save again. Do not use a space.
A section disappears after saving.All its eyebrow, heading, description and list fields are empty, or the section was deleted.Restore the required content or restore the current record if recovery is intended.
The live site shows old content.WordPress, hosting, CDN or browser cache.Clear caches and confirm Plugin 2.6.1 and Theme 3.5.1 are active.
Original wording briefly appears before edited wording.An older fallback-first theme is still active or cached.Install Theme 3.5.1 and clear all caches. The updated theme shows a neutral loader until current WordPress content resolves.
An image is missing.No Media Library attachment, inaccessible file or cached response.Choose/replace the image, update the record and clear caches.
Changes appear on more than one card.Several components reference the same service record.Remember that the Services-directory summary is shared anywhere that service appears as a preview.
See more does not appear.The hero introduction is below the automatic threshold or the text was entered in a different field.Use Hero introduction; the control appears only when the combined copy exceeds about 330 characters.
Final rule: short promotional copy belongs in cards; complete client wording belongs in hero introductions, dedicated page fields or flexible sections. This preserves the wording and the design at the same time.

Support information to record before reporting an issue

  • The exact WordPress record and field name.
  • Plugin and theme versions.
  • A screenshot of the editor field and the resulting page.
  • Whether the issue occurs on desktop, mobile or both.
  • Whether caches were cleared.
  • Whether Restore original content was used.
