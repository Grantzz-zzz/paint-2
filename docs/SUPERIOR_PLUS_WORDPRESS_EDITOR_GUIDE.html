Start safely

Before editing anything

  • Confirm Superior Plus Content 2.5.9 is active under Plugins.
  • Confirm Superior Plus theme 3.4.10 is active under Appearance → Themes.
  • Clear WordPress, hosting/CDN and browser caches after installing an update.
  • Download a JSON safety copy from the Superior Plus recovery/backup screen.
  • Edit one page and preview it before performing a large batch of changes.

Essential workflow

How to change one field safely

1

Open the correct Page, Service, Article, Project, Testimonial or FAQ record.

2

Locate Superior Plus editable content. Do not edit unrelated controls.

3

Change only the required field. For a card, edit the corresponding row/item rather than replacing the entire section.

4

Click Update, open the public page in a private window, and verify desktop and mobile presentation.

5

If live content looks unchanged, purge caches. Do not repeatedly restore or re-import.

Blank fields: the rule

SituationResult
Field is blank in the plugin, original content is visible, and you leave it untouchedThe original content remains visible. Plugin 2.5.9 ignores that untouched empty control.
Field contains saved content and you replace itOnly that content changes.
Field contains saved content and you clear itIt is treated as an intentional removal and stays hidden.
Field starts blank but shows original content, and you want to hide the originalEnter TEMP, Update, reopen, delete TEMP, and Update again. A space does not count because spaces are trimmed.
Page was damaged before plugin 2.5.9Use Restore this item once, then edit normally.
Restore and delete

Removing content without damaging the page

Delete text

  1. If the field already contains text, clear it and Update.
  2. If the field is blank but original text is visible, use the TEMP two-save method described above.
  3. Verify that only the intended heading, paragraph or CTA disappeared.

Remove a repeatable card

  1. Open the repeatable list/card field.
  2. Use its Remove/Delete control on the exact row.
  3. Do not blank every row unless the entire section should be empty.
  4. Update and verify card count and order.

Restore original content

Restore this item affects only the open record. It republishes that page/item, deletes its managed customisations, and rebuilds its bundled original content. It does not reset the whole site or Site Settings.
  1. Open the damaged item.
  2. Find Restore this item.
  3. Use it only after confirming the correct page/service is open.
  4. After restoration, edit only the required field and Update.

Never do this

  • Do not run a full approved-site import merely to repair one page.
  • Do not delete core pages and recreate them manually.
  • Do not edit generated files under react-dist.
  • Do not alter URLs/slugs casually; navigation and routing depend on them.
Cards and media

Adding and organising cards

Control typeHow to use it
List — one per lineEach line becomes one card/item. Add a line to add a card; remove a line to delete it.
Heading | DescriptionEach repeatable row has a heading and body. Both belong to the same card.
Relationship selectorSelect existing Services, Projects, Testimonials, Articles or Pages. Create/edit the source record separately.
GalleryAdd Media Library items, replace them, remove them, reorder them, edit captions/alt text, and set crop position where available.

Images

  • Use clear WebP/JPEG images with consistent orientation.
  • Write useful alt text describing the actual project or location.
  • Use Replace to retain the card position while changing its image.
  • Removing every image from a configured gallery intentionally empties that gallery.
  • Suburb card images are edited on the individual suburb record, not the Areas overview page.
Colours, icons, spacing, animation and card shape are design-locked. Content editors should change wording, images and selection; theme styling should remain consistent.

Navigation

Menus, links and the Home page

Navigation is managed through the WordPress menu assigned by the theme. Page content edits should not reorder the menu.

  1. Open Appearance → Menus (or Appearance → Editor → Navigation, depending on WordPress).
  2. Edit the theme’s assigned primary menu only.
  3. Home must point to the real homepage, normally /, not a duplicated URL ending in -2.
  4. Our Process must point to /our-process/.
  5. Keep Services children beneath Services if the dropdown is required.
  6. Save and test desktop plus mobile navigation.
Do not create a second “Home” page to repair a menu link. Confirm Settings → Reading uses the intended static homepage and then select that existing page in the menu.

Troubleshooting

If something disappears or looks wrong

Section disappeared after editing

  1. Confirm plugin 2.5.9 and theme 3.4.10 are active.
  2. Clear all caches.
  3. If the page was damaged under an older plugin, use Restore this item once.
  4. Edit one field and verify again.

Original content is visible but plugin field is blank

This is normal fallback behaviour. Leave it blank to keep the original. Enter replacement content to override it. Use the two-save TEMP method only when intentionally hiding it.

Card image is missing

  • Service card: check the Service hero/featured media.
  • Suburb card: check Directory card image on that suburb record.
  • Project card: check Featured project image.
  • Repeatable gallery card: confirm the Media Library item still exists.

Card colour is white

Update to plugin 2.5.8+ and theme 3.4.9+. Canonical related-service tones are now supplied by both plugin and theme fallback.

Live differs from localhost

  • Verify active package versions.
  • Purge cache/CDN and hard-refresh.
  • Compare the live plugin data with the restored original record.
  • Do not assume uploading only the theme is enough; theme and plugin releases work together.
Final checklist

Before finishing an editing session

  • Only the intended wording/images changed.
  • Untouched sections remain visible.
  • All new cards have complete headings and descriptions.
  • Images have useful alt text and acceptable crops.
  • CTA buttons point to valid paths.
  • Desktop and mobile navigation work.
  • Forms still submit and required fields remain present.
  • FAQ accordions open correctly.
  • No page URL gained an unwanted -2 suffix.
  • WordPress/hosting/CDN cache was cleared.
  • A new JSON safety copy was downloaded after major approved changes.
Safe rule to remember: edit content through the field that owns it; edit linked card content on its source record; leave design controls locked; restore only the damaged item.
